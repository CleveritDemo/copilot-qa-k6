# Performance Testing with k6

This project is designed to demonstrate performance testing capabilities using k6. It includes various test scenarios to evaluate the performance of a web application under different conditions.

## Project Structure

The project is organized as follows:

```
copilot-qa-k6
├── performance
│   ├── config
│   │   └── options.json         # Configuration options for performance tests
│   ├── data
│   │   └── test-data.json       # Data files required for the tests
│   ├── reports
│   │   └── placeholder.txt       # Placeholder for test reports
│   └── tests
│       ├── load-test.js         # Load testing scenario
│       ├── spike-test.js        # Spike testing scenario
│       ├── soak-test.js         # Soak testing scenario
│       └── stress-test.js       # Stress testing scenario
├── package.json                  # npm configuration file
└── README.md                     # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd copilot-qa-k6
   ```

2. **Install dependencies**:
   Ensure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Configure test options**:
   Edit the `performance/config/options.json` file to set your desired test parameters, such as duration and number of virtual users.

4. **Prepare test data**:
   Update the `performance/data/test-data.json` file with any necessary input data for your tests.

## Running Tests

You can run the performance tests using the following commands:

- **Load Test**:
  ```bash
  k6 run performance/tests/load-test.js
  ```

- **Spike Test**:
  ```bash
  k6 run performance/tests/spike-test.js
  ```

- **Soak Test**:
  ```bash
  k6 run performance/tests/soak-test.js
  ```

- **Stress Test**:
  ```bash
  k6 run performance/tests/stress-test.js
  ```

## Reports

After running the tests, the results will be stored in the `performance/reports/placeholder.txt` file. You can replace this placeholder with actual report files generated by k6.

## Conclusion

This project serves as a foundation for performance testing using k6. You can extend it by adding more test scenarios or customizing existing ones to fit your application's needs.
